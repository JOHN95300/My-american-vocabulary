MY AMERICAN VOCABULARY 2.0 - MISE A JOUR

1. SUR L’IPHONE : ouvrir la version 1 > Sauver > Exporter une sauvegarde complète (.json). Vérifier que le fichier se trouve dans Fichiers. Ne pas supprimer l’ancienne application.
2. SUR GITHUB : dans le dépôt My-american-vocabulary, remplacer index.html par celui du dossier v2 et ajouter manifest.webmanifest, sw.js et icon.svg à la racine. Le README-MISE-A-JOUR.txt n’est pas nécessaire sur GitHub.
3. Attendre le déploiement GitHub Pages, puis ouvrir l’adresse habituelle sur Safari et actualiser.
4. Vérifier les anciens mots AVANT de modifier ou supprimer quoi que ce soit. Si les mots manquent, aller dans Sauver > Importer et choisir le fichier JSON exporté. L’import ajoute sans effacer les mots présents.
5. Tester la prononciation et le mode avion APRÈS une première ouverture connectée. La voix américaine dépend des voix installées sur iOS et peut être indisponible hors connexion.

IMPORTANT : la version 2 conserve exactement la clé localStorage de la version 1 : my-american-vocabulary-v1. Les sauvegardes JSON v1 restent compatibles. Les données locales sont propres à l’origine et parfois au contexte Safari/application écran d’accueil. Une sauvegarde JSON est donc indispensable.
