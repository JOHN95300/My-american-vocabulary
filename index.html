Sauvegarde et transfert

Les mots sont enregistrés dans ce navigateur sur cet appareil. Pour éviter toute perte, exporte régulièrement ton vocabulaire.

L'import ajoute les mots sans effacer les mots existants. Les doublons identiques sont ignorés. Pour le CSV, les colonnes attendues sont : français, anglais, note.

Important : ouvrir le fichier sur un autre téléphone ne synchronise pas automatiquement les données. Utilise l'export et l'import pour les transférer. N'efface pas les données du navigateur sans sauvegarde.

La restauration intégrale nécessite une confirmation et remplace les fiches actuelles. Effectue une sauvegarde avant de l’utiliser.
